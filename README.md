# Русскоязычный NER и локальное маскирование

Дообучение RuBERT-tiny2 для выделения чувствительных сущностей в тексте. Выход — символьные интервалы `[start, end)` с типом; оценка требует точного совпадения обеих границ и типа. Маскирование выполняется локально, внешняя LLM для него не нужна.

## Эксперимент

Исходная локальная разметка: 8 287 строк, 30 типов сущностей. Одинаковые тексты объединены до разбиения; тексты с противоречащей разметкой исключены. Train/validation/test: 5667/1214/1215. Seed 42, три эпохи, AdamW, learning rate 5e-5, batch size 16. Окна 256 токенов с перекрытием 64 позволяют обрабатывать длинные тексты.

BIO-модель не представляет вложенные сущности: документы с пересечениями исключаются из обучения, но полная разметка сохранена для оценки. Выбор checkpoint — по строгому entity micro-F1 на validation. Test используется после выбора checkpoint. Разбиение защищено от точного совпадения текстов; разделение по шаблонам и источникам не проводилось.

## Результаты

На test: precision **0,8479**, recall **0,8997**, strict micro-F1 **0,8730**. Validation F1 выбранного checkpoint: 0,8652. Per-type результаты, число TP/FP/FN и параметры сохранены в [results/verified_20261010](results/verified_20261010).

На общих для двух методов типах Email и «Номер телефона»: regex F1 **0,8431** (TP=43, FP=0, FN=16), RuBERT F1 **0,9355** (TP=58, FP=7, FN=1). Модель пропускает меньше сущностей, но даёт больше ложных срабатываний. Сравнение пересчитано по сохранённым per-type счётчикам того же test, без нового обучения: [common_types.json](results/verified_20261010/common_types.json). Добавление правил к модели не изменило итоговый результат.

## Запуск

```text
pip install -r requirements.txt
python train.py --data path/to/train_dataset.tsv --output results/new_run
python -m pytest -q tests
```

TSV должен содержать `text` и `target`; `target` — список троек `(start, end, type)` в синтаксисе Python. Разметка проверяется до обучения. Сырые тексты и веса модели в репозиторий не включены. Контрольная сумма исходного файла, параметры, разбиение по хешам текстов и обезличенные интервалы предсказаний сохранены для аудита. Для повторного обучения нужен доступ к исходной разметке.

`ner.mask(text, spans)` объединяет пересекающиеся интервалы и заменяет их маркером. Полнота NER ниже 100%: это исследовательский конвейер, а не гарантия удаления всех персональных данных. Ошибки определения типа и пропущенные сущности требуют отдельного контроля в прикладном сценарии.

Базовая модель: [cointegrated/rubert-tiny2](https://huggingface.co/cointegrated/rubert-tiny2). Новый законченный эксперимент выполнен в октябре 2026; не приписывается историческому конкурсному прогону.

Пересчёт сравнения на общих типах:

```text
python compare_common_types.py results/verified_20261010/metrics.json --output results/verified_20261010/common_types.json
```
